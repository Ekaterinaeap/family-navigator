# Путеводитель российской семьи — концепт-прототип

Прототип раздела «Жизненные ситуации» в стиле портала Госуслуг. Проект «Уверенность в будущем», программа «Код лидера».

**Не является официальным сервисом.** Тексты — черновик, проверяются экспертами.

- `index.html`, `styles.css`, `app.js` — статический сайт без сборки (hash-маршруты).
- `data.js` — каталог: 10 сфер, 36 ситуаций, 4 наполненных путеводителя. Новая ситуация добавляется в `spheres[].situations` и `situations`/`stubs`.
- QR-вход из книги: `#/s/<slug>`, все коды для печати — `#/qr`.
